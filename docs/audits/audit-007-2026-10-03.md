# Design review 007

Date: 2026-10-03
Scope: the landing state as a whole, judged on identity rather than compliance. All
previous gates still pass; that is the problem. A page can clear every filter and still be
a void. This audit is about the void.
Mode: audit after. Nothing below has been fixed yet.

## Findings

### 1. The landing has no identity — R-20 — MEDIUM

Run the swap test from the core rule: cover the word "Get" and ask what product this is. The
answer is any dashboard. Flat white page, thin grey borders, system sans, one orange button,
mono chips. The decision view earned an identity (the trace rail, the accent rule, the
provenance typography); none of it reaches the landing. A first-time judge meets the product
here, and here it has nothing to say about itself.

### 2. The type has no character — R-06 — MEDIUM

Everything is the platform sans at various sizes. The call is larger sans, the labels are
smaller caps sans, the evidence is regular sans. Size is doing all the work that voice should
share. A console whose whole argument is trustworthiness should not sound like a settings
page. The fix is a pairing with a stated reason, from fonts already on the machine so the
demo never depends on a network font: a serif with editorial weight for the call and the
chain claims, sans for interface, mono for machine provenance (which is already the rule).

### 3. The empty state is a flat stack — R-05, RHYTHM — MEDIUM

Eyebrow, chips, paragraph, button, hint, each full width, each the same composition. The page
declares RHYTHM 2 and ships uniformity. The empty state is the one place on this screen
allowed to compose: numbered steps on the rail motif (01 sources in, 02 skills assigned,
03 one call out), so arrival teaches the pipeline by shape, not by paragraph.

### 4. The sidebar shouts, the content whispers — R-31 — MEDIUM

SITUATION, WHAT HAS HAPPENED, SOURCES, AUDIT TRAIL: four uppercase letterspaced labels
against a 24px product name and a quiet tagline. The loudest text on arrival is furniture.
Either the labels drop to sentence case at UI size, or the rail stops pretending to be
furniture and commits to being an instrument panel. Halfway is what it is now.

### 5. The paper is not paper — R-29 — LOW

`--sb-page` is `#FFFFFF`, clinical white, with `#F7F7F5` one step away. The direction says
warm-neutral paper and the screen says hospital. Warm the page until it reads warm
(`#FAF6EF` region), deepen the surface to hold the gap, re-measure the fourteen roles. The
numbers will still pass; ink on warm paper passes further than ink on white.

### 6. The accent never gets its moment — R-31 — LOW

Orange currently means buttons. On a landing with no decision yet, the accent should mark the
single thing that matters: the CTA and one rule beside it. Everything else stays ink and
muted. This is already the rule; the landing just never applies it.

## Not findings

- The mock-status line is correctly quiet and stays verbatim.
- The dropzone sentence stays verbatim. It is still the best sentence on the page.
- No gradients, no glass, no icons, no illustrations are proposed or wanted. The way out of
  sterile is voice and composition, not decoration.
