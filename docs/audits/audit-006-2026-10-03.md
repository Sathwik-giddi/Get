# Design review 006

Date: 2026-10-03
Scope: the landing state only: masthead, engine notice, empty main area, sidebar on first
paint. The decision view was verified in `audit-003`/`audit-005` and is not re-litigated.
Mode: audit after. Nothing below has been fixed yet.

## Findings

### 1. The screen contradicts itself on arrival — C-2, R-26 — HIGH

`App.jsx:78-100`. `loadPreset` fetches the scenario's demo files, but nothing calls it on
mount. First paint shows "Convoy B / Narmada corridor" selected, its text in the box, zero
files attached, and a dead primary button at 0.55 opacity with a paragraph explaining there
is nothing to reconcile. Every visible element claims a situation is loaded except the one
that loads it. The fix is to call the existing loader once on mount, so the visible state is
always true and Decide now is alive on first paint. No new code paths, no auto-run.

### 2. The empty main area orients nobody — C-3, R-27 — MEDIUM

When there is genuinely no run (all files removed), the main column holds the masthead, the
engine notice, and a void down to the fold. A judge opening this page learns nothing: not
what goes in, not what comes out, not what to do. The empty state should carry the pitch in
one strip: three source chips, the three pipeline steps, one line naming the single action
that fills the screen. Text and existing tokens only, no illustration.

### 3. The honesty banner is the focal point — R-31 — MEDIUM

The mock notice is the largest, most colorful block on arrival, and its message is "distrust
this page." R-38 requires the statement, not the volume. Demote it to a quiet status line
under the masthead in the existing muted meta style, keeping every word including the
`GEMINI_API_KEY` instruction. The gate's "engine state is stated in words" check must keep
passing on the exact surviving sentence.

### 4. History crowds the job on arrival — C-3, R-31 — LOW

The sidebar opens with eight audit rows, currently eight identical 93% lines, above and below
the fold pressure on the inputs. History is reference; the inputs are the job. Cap the
sidebar list at five with the caption updated to match, so the trail stays scannable without
pretending runs did not happen.

### 5. The scenario box cuts mid-sentence — C-4 — LOW

Four lines of preset text in a three-line box, with only a resize handle as affordance. It
reads as broken in screenshots. Size the field to fit the preset text it ships with.

### 6. No direction for the landing state — R-37 — LOW

`DESIGN.md` covers the call, the rail, the reference column, and the officer section. It says
nothing about arrival: what the first paint must show, where honesty lives in the hierarchy,
or what the empty state carries. Any fix above adds the entry with it.

## Not findings

- The washed-out Decide now button is a symptom of finding 1, not its own defect. The
  disabled style is correct; it is only ever seen when it should never be seen.
- The audit rows are real data and stay. Finding 4 caps the count, not the honesty.
- Copy in the sidebar passes. The dropzone line ("The disagreement between them is the
  point") is the best sentence on the page and stays verbatim.
