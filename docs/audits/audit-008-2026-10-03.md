## What changed

(`#B9B6AD`, 8.93:1) for labels, hints, and table metadata. Inputs and file rows sit one
step up (`#1E2126`) with the same hairline serving both themes (4.66:1 on the rail fill).
Focus rings go paper inside the rail. The uppercase labels stay, because on an instrument
panel they read as panel, not shouting. Finding 4 resolved by commitment, not by change.

The call and the chain claims set in Georgia, system stock, zero network dependency. Sans
keeps the interface, mono keeps machine provenance. A verdict now sounds editorial rather
than administrative, which is what trust reads as.

The page warms to `#FAF6EF` with the surface deepened to `#F1ECE1`. Ink and muted clear
both easily; the accent was never set as text on the surface and still is not.

The empty state teaches by shape: the same numbered rail as the decision view, three steps,
ending in the single action. Arrival now orients a first-time judge in one glance.
