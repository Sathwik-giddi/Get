# Design review 010: fix report for audit-009

Date: 2026-10-03
Scope: all four findings of `audit-009-2026-10-03.md`, approved together.

## What changed

1. The plan rail is gone from the main view. The reasoning chain is the only rail. What
   survives of the plan is one summary line (skill calls across sources, decided by which
   step) plus the full plan in the raw trace. Eight repeating items became three that each
   say something new.
2. Confidence is one strip: figure, bar, rationale, run metadata in reading order. The run
   metadata shortened to run id, engine, and latency, since calls and sources moved to the
   summary line where they belong.
3. "Rejected first" folds into a native disclosure widget. Evidence, risks, and the
   escalation trigger stay open. Nothing was deleted; one section changed posture.
4. The heuristic planner names real sources with real jobs per row. No two rows are
   interchangeable anymore.

Dead code went with it: the plan-step rendering, the rail divider, the old confidence
column rules, and the unused skill import.
