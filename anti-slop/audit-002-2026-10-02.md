# antislop audit 002

Date: 2026-10-02
Scope: fixes for findings 1 through 7 of `audit-001-2026-10-02.md`
Direction: `DESIGN.md`, approved before any of this was applied

Design Read: *operations console for a duty officer who must act or escalate in under 30
seconds, procedural language, dials ENERGY 2 / RHYTHM 2 / MOTION 1.*

## Fixes

### 1. Em dashes removed — R-02

`README.md` and `ui/app.py` now contain zero `—` characters, verified by scan. The three in
the UI were in the mock-mode warning, the evidence line and the raw-output line; each became a
full stop or a colon. `anti-slop/audit-001-2026-10-02.md` still contains them, which the core
carve-out exempts as rule documentation.

### 2 and 6. Direction applied — R-37, R-01, R-29

`DESIGN.md` written and applied. Warm-neutral paper replaces Streamlit's blue-grey. One accent
(`#C2410C`) now appears on exactly two things: the left rule beside the call, and the primary
control. Confidence bar uses the accent rather than Streamlit's default blue, so the bar and
the call read as the same decision. The three unmotivated status colors are gone from the
header, replaced by a functional state line plus the measured palette below.

The identity motif is built: a vertical trace rail carries the plan and the reasoning chain as
one continuous line of custody, with the source ids in the gutter and the accent marking
`make_decision`, the only skill allowed to decide.

### 4. Empty and error states — R-27

The audit table's empty state now says why the table is empty (no run has been decided on this
service) and what fills it (pick a situation, attach sources, press Decide now). The three
failure paths now separate: unreachable service, service answering something unreadable, and
service rejecting the run. Each names the cause and the next action, and the rejection path
says explicitly that nothing was recorded, so a failed run is not mistaken for a decision.

### 5. Decorative emoji removed — R-04

The page icon, the 🎯 and 🔧 plan marks, and the ✅ / ⚠️ evidence marks are gone, verified by
scanning rendered text for any codepoint above `U+2190`. Evidence stance is now a text label
(`FOR`, `AGAINST`, `CONTEXT`) in a measured color, so it survives color-blindness and forced
colours. Plan steps are distinguished by role rather than by glyph: `make_decision` takes the
accent rail and an inverted number badge, perceptual skills take the hairline rail.

### 7. Header copy rewritten — R-16

"Multi-modal decision agent. It plans, selects skills, executes them, and shows its work."
became "One situation, several sources, one call you can check." The triad is gone, and the
sentence now states what the screen is for. The button reads "Decide now" rather than "Run
Space Bunny", because the officer's task is to decide, not to run a program. README opening
rewritten the same way.

### 8. Comments — unchanged

Still a PASS. No comments were added; the CSS block carries a specificity note explaining why
the rules are prefixed, which is the kind of comment that earns its place.

## Defects found during the fix

Two were real bugs that the earlier screenshot pass had not caught, both fixed:

- **Every `p`-based rule was losing.** Streamlit's emotion cache applies `font-size: inherit`
  to `p` at specificity 0,1,1, which beat our 0,1,0 rules. The call rendered at 16px instead of
  33px, so the one thing the design calls for as its focal point was invisible as a focal
  point. Fixed by prefixing the block with `.stMarkdown` and `.stApp`, and the gate now asserts
  the rendered sizes rather than trusting the stylesheet.
- **The rail read 5, 1, 2, 3.** Plan steps and reasoning steps share one rail, so two
  independent numbering sequences ran into each other. Fixed with a labelled dashed divider
  between the plan and the chain.

`tests/test_gate.py` now fails if the first one ever regresses, since it measures the rendered
page.
